## 🤝 How to Contribute

Contributions are welcome! This repository is intended to grow as a collaborative space for MCA students to share knowledge, improve code quality, and learn together.

###  Contribution Guidelines

To maintain a clean and organized repository, please follow these guidelines:

1. **Keep it organized:** Place your contributions in the appropriate semester and subject directory.
2. **Use meaningful names:** Give files descriptive names.
3. **Add documentation:** Include an algorithm, comments, or a short explanation wherever appropriate.
4. **Respect academic integrity:** Submit your own work or properly acknowledge the original source.
5. **Keep contributions relevant:** Ensure that additions are related to MCA coursework, programming, practicals, or academic learning.

### How to Contribute

#### Step 1: Fork the Repository

Visit the repository and click the **Fork** button.

🔗 [Fork CUTM Repository](https://github.com/aayush-xid-su/CUTM/fork)

This creates a copy of the repository under your GitHub account.

#### Step 2: Clone Your Fork

Replace `YOUR-USERNAME` with your GitHub username.

```bash
git clone https://github.com/YOUR-USERNAME/CUTM.git
cd CUTM
```

#### Step 3: Create a New Branch

Create a separate branch for your contribution.

```bash
git checkout -b feature/your-contribution
```

#### Step 4: Add Your Contribution

Add your files to the appropriate directory.

*Use the existing directory structure where possible. The example above illustrates a possible organization.*

#### Step 5: Commit Your Changes

Stage your changes:

```bash
git add .
```

Commit them with a descriptive message:

```bash
git commit -m "feat: add C programming examples"
```

#### Step 6: Push Your Branch

```bash
git push origin feature/your-contribution
```

#### Step 7: Open a Pull Request

1. Open your fork on GitHub.
2. Select **Compare & pull request**.
3. Set the base repository to `aayush-xid-su/CUTM`.
4. Select the appropriate target branch, usually `main`.
5. Describe your changes clearly.
6. Submit your pull request for review.

Your contribution can be reviewed before it is merged into the main repository.
